### Deskripsi
Aplikasi My Store merupakan sistem pengelolaan data user dan produk berbasis web menggunakan PHP dan MySQL.

### Fitur Aplikasi
1. Login Admin
2. Dashboard Admin
3. CRUD User
4. CRUD Produk
5. Pencarian Data
6. Logout Admin
7. Menampilkan minimal 25 produk dummy

### Teknologi
- PHP
- MySQL
- HTML
- CSS
- JavaScript
- Bootstrap tidak digunakan

### Database
Nama Database: db_uts

Tabel:
- users
- produk

### Cara Menjalankan
1. Aktifkan Apache dan MySQL di XAMPP.
2. Simpan folder project di htdocs.
3. Import atau buat database db_uts.
4. Buka browser.
5. Akses http://localhost/uts-crud/login.php
